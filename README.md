## 🚀 Featured Projects

### 🏦 [CreditWise Loan System](https://github.com/YOUR-USERNAME/CreditWise-Loan-System)
> *ML-powered binary classification system for automated loan approval*

Built for a mid-sized bank to replace a biased, time-consuming manual review process.
Engineered features across 20+ applicant attributes, trained and compared multiple classifiers
(Logistic Regression, Random Forest, XGBoost, LightGBM), and optimized for both precision and recall
to minimize defaults without rejecting good applicants.

`Python` `Scikit-learn` `XGBoost` `Pandas` `Feature Engineering` `Classification`

---

### 🤖 [Gemini RAG System](https://github.com/YOUR-USERNAME/Gemini-RAG-System)
> *Context-grounded Q&A app that forces the LLM to stay in its lane*

A Retrieval-Augmented Generation (RAG) application built with Google Gemini 2.5 Flash Lite and Streamlit.
Upload any document (TXT, MD, PDF, DOCX) and ask questions — the model answers only from
what's in your file, not from the open internet. No hallucinations. No guessing.

`Python` `Google Gemini API` `RAG` `Streamlit` `Prompt Engineering` `LLM`

---

### 🎬 [Movie Recommender System](https://github.com/vinay-271/Movie-Recommendation-System)
> *Content-based recommender using NLP and cosine similarity*

Processes the TMDB 5000 dataset by combining genres, cast, crew, keywords, and plot overviews
into a single feature tag per movie. Applies stemming, Bag-of-Words vectorization, and cosine similarity
to surface the 5 closest matches — deployed as an interactive Streamlit web app.

`Python` `NLTK` `Scikit-learn` `Cosine Similarity` `Streamlit` `NLP`
